# Reminder for Windows — задачи и процессы

Настольное приложение для Windows, которое помогает управлять напоминаниями и многошаговыми процессами. Оно показывает уведомления, поддерживает процессы с ветками и зависимостями и хранит данные локально в SQLite.

## Проблема

При работе с задачами важно вовремя получать напоминания и не терять последовательность действий. Особенно это актуально для процессов, в которых выполнение одного шага зависит от другого, а работа может растянуться на несколько дней.

## Решение

Reminder for Windows объединяет отдельные напоминания и процессы из нескольких шагов. Для процессов можно задавать ветки, зависимости и расписание уведомлений, а также создавать собственные шаблоны в визуальном конструкторе.

## Что внутри

- Напоминания с уведомлениями и возможностью отложить выполнение.
- Многошаговые процессы с ветками, зависимостями, чек-листами и эскалацией уведомлений.
- Визуальный конструктор пользовательских шаблонов процессов.
- Локальная база SQLite и работа приложения в системном трее.
- Основной интерфейс на Python и Tkinter; конструктор на React, открываемый через pywebview.

## Результат

Создано настольное приложение для Windows, которое объединяет напоминания и управление многошаговыми процессами. Пользователь может настраивать уведомления, работать с готовыми шаблонами и создавать собственные схемы процессов.

## Возможности

- Добавление напоминаний с заголовком, описанием и временем срабатывания
- Дата выбирается в выпадающем календаре, время — стрелками часов, минут и секунд
- При наступлении напоминания приложение пытается показать системный баннер Windows и открывает собственное окно. Баннер может исчезать автоматически; собственное окно ожидает действия пользователя.
- Статусы: «Ожидает», «Готово», «Просрочено», «Отменено»
- Автоматический перевод в «Просрочено» через минуту после пропущенного времени
- Фильтр списка по статусу
- Отметка «Готово» / «Отменено» для всех выбранных записей; удаление выбранных с одним подтверждением
- Щелчок по строке добавляет её в выбор или убирает; Shift+щелчок выделяет диапазон; Delete удаляет выбранные
- Записи со статусом «Готово» автоматически исчезают из списка через сутки
- Кнопка «Просроченные» ставит фильтр; «Возобновить» возвращает выбранные просроченные на новую дату вручную
- Кнопки быстрой установки времени: +1, +5, +15, +30, +45 минут и +1 час
- Работа в системном трее: закрытие окна не останавливает напоминания
- Отложить напоминание: на 5 минут или на выбранную дату и время — из всплывающего окна и из списка (одиночные и шаги процесса)
- Копирование и вставка (Ctrl+C / Ctrl+V) в полях форм
- Вкладка «Процессы»: дерево процесс → ветка → шаг, создание по шаблону
- Встроенные шаблоны «ЭДО-договор» и «Охрана объекта»
- Конструктор процессов: свои шаблоны (ветки, шаги, связи, чек-листы, эскалация) без правки встроенных; копирование шагов, несколько входящих зависимостей, правка сохранённого шаблона
- Эскалация — список шагов «Через» / «В время»: можно добавить, удалить, поменять порядок; последний шаг повторяется, пока процессный шаг не закрыт
- Расписание уведомлений шага видно в дереве и правится у любого незакрытого шага, в том числе если эскалации ещё не было
- У чек-листа и эскалации есть дата «Действует с»; пусто — свойство работает сразу
- Уведомления процесса по умолчанию только в пн–пт с 09:00 до 18:00; галочка «Уведомлять в выходные» включает сб–вс в том же окне времени. Одиночные напоминания по-прежнему на любое время суток
- В конструкторе шаг переименовывается щелчком по названию на холсте; поле в панели «Свойства» остаётся
- Блокирующий чек-лист: шаг нельзя закрыть, пока не отмечены все пункты; до даты «Действует с» пункты видны, но неактивны
- Отложенная ветка охраны активируется за 3 дня до даты окончания услуг

## Установка и запуск

Для запуска нужны Windows 10 (начиная с версии 1607) или Windows 11 и Python 3.10 или новее с `pip` и `tkinter`.

1. Установите [Python для Windows](https://www.python.org/downloads/windows/). В установщике включите **Add python.exe to PATH** и компонент **tcl/tk and IDLE**.
2. Откройте PowerShell и проверьте Python и Tkinter:

   ```powershell
   python --version
   python -m pip --version
   python -c "import tkinter; print('tkinter ok')"
   ```

3. Выберите один из способов получения программы ниже. В командах замените пример пути на свою папку. Выполняйте команды из папки, где находится `main.py`.

### Вариант 1. Архив проекта

1. Скачайте [архив версии 2.3.1](https://github.com/dmitrijtrudradost/reminder-for-windows/releases/download/2.3.1/reminder-for-windows-2.3.1.zip) и распакуйте его, например, в `C:\Reminder_for_Windows`. Убедитесь, что в этой папке находятся `main.py`, `requirements.txt` и `process_builder_web/dist/index.html`.
2. В PowerShell выполните:

   ```powershell
   cd C:\Reminder_for_Windows
   python -m pip install -r requirements.txt
   python main.py
   ```

В архиве 2.3.1 есть собранная веб-часть, поэтому Node.js для этого способа не нужен.

### Вариант 2. Исходники GitHub

1. Скачайте исходники через **Code → Download ZIP** на странице репозитория и распакуйте их либо клонируйте репозиторий. Откройте PowerShell в распакованной папке, содержащей `main.py`.
2. Установите [Node.js с npm](https://nodejs.org/) и убедитесь, что доступны `node --version` и `npm --version`.
3. Из корня проекта соберите веб-часть конструктора:

   ```powershell
   cd process_builder_web
   npm ci
   npm run build
   cd ..
   ```

   Убедитесь, что создан `process_builder_web/dist/index.html`. Без этой сборки конструктор процессов не откроется; повторите сборку после изменения веб-части.
4. Из корня проекта установите зависимости Python и запустите программу:

   ```powershell
   python -m pip install -r requirements.txt
   python main.py
   ```

После запуска откроется окно приложения, а в рабочей папке появится база `reminders.db`. Закрытие окна крестиком сворачивает приложение в трей; для полного выхода выберите **Выход** в меню значка. Если конструктор не открывается, проверьте наличие [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).

Согласно прежней инструкции проекта, базы версий 1.1–2.1 открываются с автоматическим добавлением необходимых таблиц и полей. При обновлении существующей установки сохраните базу и следуйте инструкции для своей версии: [2.1 → 2.2](UPDATE-2.2.md) или [2.2 → 2.3](UPDATE-2.3.md).

Подробности об автозапуске и дополнительных вариантах установки — в [INSTALL.md](INSTALL.md).

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `main.py` | Точка входа: связывает модули, запускает приложение и корректно его закрывает |
| `database.py` | Класс `ReminderDatabase` — вся работа с SQLite3 |
| `notifications.py` | Класс `NotificationManager` — фоновый мониторинг и показ уведомлений |
| `gui.py` | Класс `ReminderApp` — интерфейс на Tkinter и иконка в трее |
| `templates.py` | Встроенные шаблоны процессов ЭДО и охраны |
| `process_builder.py` | Окно конструктора процессов (pywebview) |
| `process_builder_web/` | Исходники визуального редактора; `dist/` создаётся сборкой и входит в архив 2.3.1 |
| `autostart.py` | Ярлык в папке «Автозагрузка» Windows |
| `INSTALL.md` | Установка на Windows 10/11 и варианты автозапуска |
| `UPDATE-2.2.md` | Обновление 2.1 → 2.2 на уже установленном компьютере |
| `UPDATE-2.3.md` | Обновление 2.2 → 2.3 на уже установленном компьютере |
| `requirements.txt` | Список зависимостей |
| `reminders.db` | База напоминаний, создаётся при первом запуске |

Подробные сведения о базе, интерфейсе и реализации — в [архитектуре проекта](ARCHITECTURE.md).
